# AJEGT ERP

ERP de gestion de l'Association des Jeunes et Étudiants Guinéens de Toulouse.

## Objectif

Centraliser la gestion de l'association :
- membres
- bureaux
- événements
- finances
- documents
- archives

## Technologies

Frontend :
- Next.js
- React
- Tailwind CSS

Backend :
- Spring Boot
- Java

Base de données :
- PostgreSQL


## Architecture

Frontend → API REST → Backend → PostgreSQL


## Fonctionnalités

- Authentification
- Gestion des membres
- Gestion des bureaux
- Gestion des événements
- Gestion documentaire
- Tableau de bord
