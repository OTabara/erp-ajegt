# Frontend ERP AJEGT

Interface React et TypeScript servie par Vite. Le premier module disponible est un prototype de gestion des membres.

## Démarrage

```bash
npm install
npm run dev
```

## Module Membres

Le prototype permet de rechercher, filtrer, créer, modifier et archiver des fiches. Les exemples sont fictifs et les données sont enregistrées dans le stockage local du navigateur. N’utilisez pas encore de données personnelles réelles : aucune authentification ou API n’est raccordée pour le moment.
